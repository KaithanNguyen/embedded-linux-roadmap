# Debug journal
Mỗi bug khó trở thành một bản ghi root cause. Mục tiêu: 1 bản ghi mỗi tuần, 10 bản ghi có ảnh logic analyzer trong Q4/2026, 30 bản ghi đến 06/2027.
Dùng [debug template](../templates/debug-report.md) cho vấn đề xuyên sprint.
Report thuộc sprint/project giữ tại chỗ; index tại đây liên kết về bản gốc.
Chỉ ghi lỗi từ lab và project cá nhân; lỗi gặp ở công việc giữ ngoài repo công khai.
Bài luyện với lỗi cài sẵn: [debug drills](../debug-drills/README.md); bản ghi của mỗi drill cũng nằm trong journal này.

| Issue | Report | Root cause | Status |
| --- | --- | --- | --- |
| microSD inspection | [Sprint debug 01](../sprints/2026-10-05_linux-workstation/debug/microsd-debug-01.md) | Chưa xác nhận | Template |

Một report hoàn chỉnh phải phân biệt rõ observed fact, hypothesis và confirmed cause.
Mỗi tháng đọc lại toàn bộ journal: loại lỗi nào hay gặp, giả định nào hay mắc; ghi khuôn mẫu vào [monthly review](../templates/monthly-review.md).
